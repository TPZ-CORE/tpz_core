```
Steam authentication PSA
Recently FiveM Legacy & RedM received an update, that changes how Steam authentication works. 

Information for server owners

Having the Steam client installed or running is no longer required for the player to have a steam: identifier. Instead players connecting to a server that requires Steam authentication will be presented with a pop-up window, which will then open a page in their default browser, letting them authorize FiveM/RedM to access their Steam account information.

If your server is on an artifact version before 38317, to support the new Steam authentication you have to update it to 38317 or later. 
Then if your server requires a Steam identifier, add set sv_enforceSteamAuth true in server.cfg. 

With these changes, FiveM will no longer sets the player's username to their username in Steam. This means that such players will get a randomized default name if they never set one. You can ask the players to set their username in the FiveM settings,  or you can develop a script to set the name for each player as they connect.This is done by calling SetPlayerName inside of the onPlayerConnecting server event. Here is an example of such a script https://gist.github.com/Exyztence/ae347eb58fe9523841af10f88e548156 

Some queue/whitelist scripts may fail to find the Steam identifier, if they made the assumption that GetPlayerIdentifier(source, 1) or GetPlayerIdentifiers(source)[1]  will always return the Steam identifier. This was never guaranteed and no longer the case. Use GetPlayerIdentifierByType(source, "steam") instead 
```
