# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added a missing configuration option `sv_maxClients`.
2. Added a new protection against multiple RedM Clients running at the same time and playing with 2 characters or more of the same steam / rockstar.

## Modified Files:

- server/users.lua
- config.lua (check notes)
- fxmanifest.lua

## Notes

1. Add the missing config option in the `config.lua`

```lua
Config.sv_maxClients = 48
```

2. Add the new config option for being protected against multiple RedM Clients.

```lua
-- Some people know how to open (2) RedM clients at the same time and play with the same steam and rockstar account, set it to true
-- to prevent them from doing such an abuse.
Config.PreventDuplicateSteamClient = true
```
