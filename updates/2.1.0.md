# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Modified `default_weapon` to `default_weapons` for supporting multiple weapons on the player loadout than only one.
2. Added an extra server event for the new characters selection. 

## Modified Files:

- server/main.lua
- server/api/api.lua
- server/player/character.lua
- server/player/loadcharacter.lua
- fxmanifest.lua

## Notes

- Use this on database query for modifying the `default_weapon` to `default_weapons`:

1st method

```sql
ALTER TABLE `characters`
CHANGE COLUMN `default_weapon` `default_weapons` LONGTEXT DEFAULT '[]';
```

2nd method in case first does not do anything

```sql
ALTER TABLE `characters`
ADD COLUMN `default_weapons` LONGTEXT DEFAULT '[]';
```

- Use this on database query for adding the played time and last play new features for character selection:

```sql
ALTER TABLE `characters`
    ADD COLUMN IF NOT EXISTS `played_time` INT(11) DEFAULT 0,
    ADD COLUMN IF NOT EXISTS `last_play` VARCHAR(50) DEFAULT '0';
```
